# 台北市長選戰 3D（SimElection）

以 [three.js](https://threejs.org/) 製作的 3D 市長競選模擬遊戲。玩法類似大富翁：候選人擲骰子沿著環繞台北市的路線前進，在各行政區設立競選辦公室、舉辦造勢、應對新聞事件，投票日時得票最多者當選台北市長。

## 快速開始

```bash
npm install
npm run dev      # 開發伺服器 http://localhost:5173
npm run build    # 輸出靜態檔到 dist/（可直接部署到 GitHub Pages 等靜態空間）
```

## 測試

```bash
npm run test:unit   # 單元測試：遊戲規則與棋盤生成（Node 內建 test runner，不需瀏覽器）
npm run test:e2e    # 端對端測試：用 Playwright 開瀏覽器自動玩完一局
npm test            # 兩者都跑
```

第一次跑端對端測試前需安裝瀏覽器：`npx playwright install chromium`。
網址加上 `?speed=8` 可加速動畫（測試時使用）。

### GitHub Actions

- **測試**（`.github/workflows/ci.yml`）：每次 push 或開 Pull Request 時自動建置並執行全部測試，結果在儲存庫的 **Actions** 分頁查看；失敗時可下載 `playwright-report` 截圖與報告。也可以在 Actions 分頁按 **Run workflow** 手動執行。
- **部署**（`.github/workflows/pages.yml`）：推送到 `main` 時自動發布到 GitHub Pages。首次使用請到 **Settings → Pages**，將 Source 設為 **GitHub Actions**。

## 遊戲特色

- **以台北市為參考的 3D 地圖**：依真實經緯度大略投影的市界、淡水河／新店溪／基隆河、陽明山等山丘、台北 101 與市政府模型，以及隨機生成的城市街廓。
- **46 格環狀棋盤**：23 個地標（台北101、西門町、士林夜市、北投溫泉、南港展覽館……）依地理順序串成迴圈，中間穿插事件格。
- **12 個行政區選情**：每區有選民數與各候選人「聲量」，投票日依聲量比例開票。
- **1～3 位電腦對手**，會依選情決定進駐、升級、投放廣告與辯論策略。

## 規則

| 格子 | 效果 |
| --- | --- |
| 🏛️ 台北市政府（起點） | 經過領政黨補助 400 萬；停留時全市聲量 +1 |
| 地標 | 花錢設立競選辦公室（該區聲量 +12）；再次停留可升級為後援會 → 造勢晚會 → 萬人大造勢 |
| 對手地盤 | 支付反制文宣費，或讓對手拉走該區聲量 |
| 📰 新聞事件 | 抽事件卡：政策獲好評、失言風波、颱風勘災、網紅合作…… |
| 💰 募款餐會 | 獲得 250～550 萬經費 |
| 📊 民調中心 | 領先者獲捐款；落後者指定一區催票 |
| 🎤 政見辯論會 | 選擇穩健／大膽／攻擊策略，風險與報酬不同 |
| 📺 媒體專訪 | 花 200 萬，指定一區聲量 +6 |
| 🚇 捷運站 | 搭捷運到下一個捷運站 |
| 🚧 交通管制 | 暫停一回合 |

- 每回合擲骰前可花 300 萬「投放廣告」，指定一區聲量 +5。
- 每週結束時，所有辦公室依等級自動累積該區聲量。
- 選戰長度可選 10／15／20 週；投票日依各區聲量比例（加上少量隨機誤差）計票。

## 操作

- 滑鼠左鍵拖曳旋轉、右鍵平移、滾輪縮放
- 點擊格子查看地標資訊與該區民調
- 空白鍵擲骰
- 右上角可切換「跟隨／總覽」鏡頭與選區民調面板

## 專案結構

```
index.html        介面骨架
src/main.js       進入點、開始畫面
src/data.js       行政區、地標、事件卡與規則數值
src/geo.js        經緯度投影、棋盤路線生成、市界與河川資料
src/scene.js      three.js 場景：地圖、格子、棋子、辦公室、骰子、特效
src/game.js       遊戲規則與回合流程、電腦對手邏輯
src/ui.js         HUD、對話框、事件卡、開票畫面
src/style.css     介面樣式
src/speed.js      動畫速度倍率（?speed=N）
tests/unit/       單元測試
tests/e2e/        Playwright 端對端測試
```

> 本遊戲中的候選人、政黨與事件皆為虛構；地圖與選民數僅為大略參考。
